Web 弱點掃描工具實務教學

歡迎來到本課程！本平臺專為資安初學者與軟體開發人員設計，全面涵蓋 OWASP ZAP 與 Burp Suite 的基礎原理、環境建置、漏洞識別及自動化掃描演練。

1. 工具介紹與詳細比較

在網站安全稽核與滲透測試中，中間人代理 (Man-in-the-Middle Proxy) 是最核心的工具類別。其中，OWASP ZAP 與 Burp Suite 佔據了業界最主要的地位。

工具定位簡述

  • OWASP ZAP (Zed Attack Proxy)：由 OWASP 維護的開源旗艦專案，強調免費、完全無限制與高度自動化，極適合整合進 DevSecOps 與 CI/CD 流程中。
  • Burp Suite：由 PortSwigger 公司開發，為商業資安團隊與滲透測試人員的標準工具，提供極強的手動分析、重放與解碼模組。

2. 核心原理與漏洞解析

代理 (Proxy) 運作機制

代理工具充當瀏覽器（用戶端）與 Web 伺服器之間的中介。當瀏覽器發送 HTTP/HTTPS 請求時，封包會先被 Proxy 捕捉，允許測試人員進行檢查、暫停與篡改，隨後再轉發至目標伺服器。

HTTPS 憑證解密 (SSL/TLS Interception)

加密網站使用 TLS 協定傳輸資料。為了使代理工具能看懂 HTTPS 裡面的明文內容，代理工具會在本地動態生成目標網站的「偽造 TLS 憑證」。

關鍵步驟：瀏覽器預設會阻斷不受信任的憑證。因此測試前，必須將工具生成的 Root CA 憑證（如 `OWASP ZAP Root CA` 或 `PortSwigger CA`）匯入並設定為「受信任的根憑證頒發機構」。

弱點掃描分類

  • 被動掃描 (Passive Scanning)：僅觀察並分析經過 Proxy 的 Request/Response，不主動發送額外封包。適用於檢測安全標頭缺失或未帶有 `HttpOnly` / `Secure` 旗標的 Cookie。
  • 主動掃描 (Active Scanning)：針對 URL 參數、Header、Body 參數等注入各種 Payload，透過觀察伺服器回覆以驗證潛在漏洞（如 SQLi、XSS）。

3. GitHub 免安裝虛擬靶場啟動指南

🚀 零安裝！利用 GitHub Codespaces 執行線上 Linux 虛擬靶場：
無須在自己電腦安裝 Docker 或各種環境，直接點擊 GitHub 頁面即可啟動雲端虛擬機！
  1. 回到本 GitHub 專案首頁，點擊右上角的綠色按鈕 <> Code。
  2. 切換至 Codespaces 頁籤，點擊 Create codespace on main。
  3. 等待網頁載入雲端 VS Code 介面（約 10~20 秒）。
  4. 在畫面下方的 Terminal（終端機） 輸入以下命令並按 Enter： 
    docker run -d -p 3000:3000 bkimminich/juice-shop
  5. 終端機執行後，切換至下方面板的 Ports (連接埠) 頁籤。
  6. 點擊 Port 3000 旁邊的網址（或右鍵選取 Open in Browser），即可開啟您專屬的線上 Juice Shop 靶場！

4. 完整步驟與實作演練

步驟一：手動封包篡改 (Burp Repeater 演練)

  1. 開啟 Juice Shop 登入頁面。
  2. 開啟 Burp Suite 的 Proxy -> Intercept is on。
  3. 輸入測試帳號點擊登入以攔截 POST 請求。
  4. 按下 Ctrl + R 將封包送至 Repeater 模組。
  5. 將 JSON 請求中的 `email` 修改為 ' OR 1=1 --，點擊 Send。
  6. 觀察右側 Response，成功獲得 HTTP 200 並返回管理者 JWT Token！

步驟二：自動化弱點掃描 (OWASP ZAP 演練)

  1. 開啟 OWASP ZAP，於主畫面點選 Quick Start -> Automated Scan。
  2. 填入靶場 URL（例如 Codespaces 生成的 Port 3000 網址）。
  3. 點擊 Attack 開始爬蟲與主動弱點掃描。
  4. 掃描完成後，切換至 Alerts 頁籤檢視自動檢出的弱點報告。

一、 測驗題目解答與詳細解析

第 1 題解答：選項 (2) 解密 TLS 加密流量...

解析：HTTPS 採用端到端加密。Proxy 為了讀取內容會動態簽發偽造憑證，若瀏覽器未信任 Proxy 的 Root CA，連線將被阻斷。

第 2 題解答：選項 (2) OWASP ZAP 為免費開源軟體...

解析：OWASP ZAP 為完全免費的工具；Burp Suite 社區版則移除了一鍵主動弱掃功能。

第 3 題解答：選項 (2) 只分析現有流量而不發送額外請求...

解析：被動掃描只監聽經過 Proxy 的 Header 與 Response，不會主動觸發安全警報。

二、 Juice Shop 實作解答 (Writeup)

管理員 SQL 注入驗證繞過

POST /rest/user/login HTTP/1.1
Content-Type: application/json

{
  "email": "' OR 1=1 --",
  "password": "anything"
}

說明：傳入 `' OR 1=1 --` 能讓 SQL 條件恆真，註解掉後續比對，直接以 Admin 身分登入。
