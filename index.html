1. 工具介紹與比較

在 Web 應用程式安全測試領域，OWASP ZAP 與 Burp Suite 是目前國際最主流的兩款 HTTP/HTTPS 代理工具。

比較項目 OWASP ZAP Burp Suite (Community / Pro)
授權與費用 完全免費 / 開源 (OWASP 專案) 社區版免費 / 專業版需付費訂閱
主動掃描能力 免費版即包含完整主動弱點掃描器 社區版無主動掃描；專業版具備 Burp Scanner
速度與限制 無人為速率限制 社區版 Intruder 功能設有速率限制 (Throttling)
最佳應用場景 DevSecOps 自動化、CI/CD 弱掃整合 資安顧問與滲透測試人員手動稽核標準工具

2. 核心原理解析

中間人代理 (Man-in-the-Middle Proxy)

弱點掃描工具會在瀏覽器與目標伺服器之間架設本地代理（預設為 127.0.0.1:8080），所有的 Request 與 Response 均會透過代理監聽與轉發。

HTTPS 憑證解密 (SSL/TLS Interception)

由於 HTTPS 流量經過加密，代理工具會動態簽發目標網站的憑證。測試者必須將工具的 Root CA 憑證 匯入瀏覽器的「受信任的根憑證頒發機構」中，才能解析加密封包。

被動掃描 vs 主動掃描

  • 被動掃描 (Passive Scanning)：僅監聽現有流量，檢測如 Security Headers 缺失、Cookie 未設 HttpOnly/Secure 等，對系統無害。
  • 主動掃描 (Active Scanning)：主動向目標注入攻擊 Payload（如 SQLi, XSS, Command Injection），觀察回應以驗證漏洞。

3. 實際操作演練 (以 OWASP Juice Shop 為例)

請開啟測試靶場 http://localhost:3000 並設定瀏覽器代理至 127.0.0.1:8080。

任務一：手動攔截與參數篡改 (Burp Suite Repeater)

  1. 開啟 Burp Suite 的 Proxy -> Intercept is on。
  2. 在 Juice Shop 登入頁輸入測試帳密，點擊登入以攔截 POST 請求。
  3. 按下 Ctrl + R 將請求發送至 Repeater 模組。
  4. 將 JSON 請求中的 email 修改為 ' OR 1=1 -- 並點擊 Send。
  5. 檢視 Response 驗證是否成功繞過密碼檢查取得管理員權限。

任務二：自動化弱點掃描 (OWASP ZAP)

  1. 開啟 ZAP，點擊 Quick Start -> Automated Scan。
  2. 輸入 URL http://localhost:3000 並點擊 Attack。
  3. 觀察 Spider（爬蟲）與 Active Scan（主動掃描）進度。
  4. 掃描完成後，切換至 Alerts 頁籤檢視自動檢出的弱點報告。
